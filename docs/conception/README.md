# Conception d'AlbumMania

Documents de travail de la refonte (octobre 2026) :

- `vision.md` : la demande du propriétaire (vision, piliers, fonctionnalités, contraintes).
- `DECISION-DESIGN.md` : décision du propriétaire, prioritaire sur tout le reste : on garde l'interface actuelle (polices, couleurs, booster).
- `design-system.md` : l'identité actuelle formalisée (jetons, composants existants et nouveaux composants dans le même style).
- `PLAN.md` : plan maître (architecture de l'information, schéma de base de données, API, algorithmes, priorités P0 à P3, chantiers).
- `audit-ux.md` : audit visuel et UX de l'interface avant la refonte.
